Daily GIF scenes for the Wattson home-screen widget app (v0.2.1).

Install the app

The APK is stored here as base64 text (app-debug.apk.b64) because GitHub's API tooling can only upload text files. To install:

base64 -d app-debug.apk.b64 > app-debug.apk
adb install -r app-debug.apk

Or build it yourself from the project source (see the Wattson widget app project): open it in Android Studio and Run, or ./gradlew assembleDebug.

A real .apk release asset will replace this workaround.
